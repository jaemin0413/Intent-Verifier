# Notion 기능명세서 연동, 팀원 개인 AI, 구 실행기 정리

2026-11-08. 검수에서 찾은 개선점과 사용자가 추가한 요구(Notion 기능명세서 입력)를 함께 반영했다.

## 결정

- **Figma REST 가져오기는 만들지 않았다.** 조사 결과 Figma REST API는 보기 권한만 있어도 파일과 PNG를 읽을 수 있었지만, 사용자가 Starter 요금제의 월 20회 제한을 이유로 취소했다. 대신 소유자가 편집자로 초대하면 기존 플러그인이 원본에서 바로 돌아가므로, **프로젝트의 연결 Figma 파일을 바꾸는 것**(복사본→원본)을 허용했다. 기존 해석·승인·검사 기록은 그대로 남고, 이전 파일의 플러그인 토큰만 끊긴다.
- **Claude 팀원 개인 연결은 두지 않았다.** Anthropic은 2026-02-19 문서 갱신으로 구독 OAuth 토큰의 제3자 도구 사용을 금지했다. 팀 서버의 Claude는 운영자 API 키만 쓴다.
- **Codex 팀원 개인 연결은 넣었다.** `codex-cli 0.166.0`의 `codex login --device-auth`가 주소(`https://auth.openai.com/codex/device`)와 일회용 코드를 출력하는 것을 격리된 `CODEX_HOME`에서 확인했다. 서버는 팀원별 홈에서 이 명령을 실행하고 주소·코드를 화면에 보여 준다. OpenAI 약관은 확인하지 못했으므로 화면에 사용자 확인 책임을 표시한다. Codex 자체 안내문은 "다른 사이트가 준 코드는 취소"라고 하므로, 화면에는 팀원 본인이 지금 시작한 로그인의 코드임을 적었다.
- **구 실행기 삭제.** Maven 기반 `lib/runner.mjs`·`generator.mjs`, 게시글 삭제 예제, 특정 프로젝트 스크랩 모듈, `fixtures/`의 Java 252개, prove 스크립트 20여 개와 그 테스트를 지웠다. `npm run prove`는 범용 Gradle 샘플(`prove-builds`)을 가리킨다. `examples/post-delete.json`은 테스트의 명세 샘플로만 남겼다.

## 바꾼 것

- **Notion 기능명세서:** 화면 보관함에서 링크를 최대 5개 넣으면 `lib/notion-documents.mjs`가 본문 블록과 하위 페이지 1단계를 읽어 `DOCUMENT`/`DOCUMENT_BLOCK`/`DOCUMENT_PAGE` 노드로 화면 원문에 합친다. 같은 원문 판별, AI 해석, 기준 작성이 모두 그 노드를 함께 본다. 해석 근거가 문서 블록 ID를 인용하면 원문 화면의 문서 항목 아래에 표시한다. 서버는 15분마다 문서를 다시 읽어 바뀌면 `documentReviewRequired`로 알리고, ‘문서 다시 읽고 재해석’을 누르면 새 내용으로 재해석한다(승인 기준 해제).
- **운영자 비밀번호:** `ADMIN_KEY`. 팀 서버에서 API 키 저장, 팀 AI 변경, 프로젝트 Notion 위치 지정은 `X-Operator-Key`가 맞아야 한다(403 `OPERATOR_KEY_REQUIRED`). 모델 선택은 팀원도 바꿀 수 있다.
- **팀원 개인 코드:** 브라우저가 32자리 난수를 만들어 `X-Member-Id`로 보낸다. 서버는 이 코드로 `members/<코드>/codex`를 두고, 그 팀원의 요청에만 개인 Codex를 쓴다. 결과 기록에 `account: member`, `memberId`가 남는다.
- **검수 개선:** 백엔드 연결 폼의 게시글 테이블 입력 제거, 삭제 화면 고정 질문과 `supportedCandidate` 규칙 제거(모든 기능이 같은 질문 흐름), Gemini 429/503 1~2회 재시도, 백엔드 연결에서 허용 폴더 검사를 폴더 존재 확인보다 먼저, 같은 경로 형태 API가 둘 이상일 때 "고르지 못함" 문구, 끝난 검사 작업 20개만 유지, 프롬프트·오류의 "Codex" 고정 표현을 AI로.

## 미확인

- 팀원 개인 Codex 로그인 완료와 그 계정으로의 실제 분석. 기기 코드 흐름은 출력까지만 확인했다.
- 실제 Notion 페이지 읽기. 응답을 흉내 낸 테스트로 블록·하위 페이지·데이터베이스 처리와 변경 감지를 확인했다. Notion 블록 종류 중 표·토글·콜아웃 등은 rich_text 기준으로 읽고, 이미지·파일은 텍스트가 없어 빠진다.
- Gemini·Claude API 키 실제 호출, 홈서버 배포, 여러 팀원 동시 사용은 이전과 같이 미확인이다.
- 문서 400블록·5개 제한을 넘는 긴 명세서는 일부만 읽고 ‘길어서 일부만 읽음’으로 표시한다.
