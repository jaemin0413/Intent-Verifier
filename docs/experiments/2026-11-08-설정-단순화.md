# 설정 단순화와 팀원별 AI

2026-11-08. 팀원은 기능만 쓰고 설정은 관리자가 한 번 하도록 화면을 바꿨다.

## 결정

- **Figma 플러그인은 유지한다.** `manifest.json` 가져오기가 곧 개발용 플러그인이고, [공식 문서](https://help.figma.com/hc/en-us/articles/360042786733-Register-a-plugin-for-development)는 "All plans"로 안내한다. 실행은 Figma Desktop과 파일 편집 권한이 필요하다. 빼면 남는 REST·MCP는 Starter에서 월 20회 수준이고, 이미지 업로드는 노드와 문구를 잃는다. 설치 방법은 화면이 아니라 README에 둔다.
- **설정은 관리자만 본다.** 팀 서버에서는 왼쪽 아래 '관리자'에 `ADMIN_KEY`를 넣어야 프로젝트 설정이 보인다. 저장 값은 서버에 있어 모든 팀원에게 적용된다.
- **팀 AI 통일 전제를 뺐다.** 팀원은 '내 AI'에서 자기 ChatGPT를 연결하고, 연결하지 않으면 관리자가 정한 기본 AI로 실행한다. 구독 연결은 ChatGPT(Codex)만 가능하다. Claude·Gemini는 [2026-11-05 약관 확인](2026-11-05-다중AI-팀해석.md)대로 API 키만 쓴다.
- **기능명세서는 프로젝트에 저장한다.** 화면별 입력을 없애 팀원마다 해석이 갈리는 경로를 막았다.

## 바꾼 것

- 프로젝트 설정 하나에 AI·Figma·Notion·백엔드를 접고 펼치는 구역으로 합쳤다. Notion 주소 입력은 API 명세서 링크 1개와 기능명세서 링크 여러 개(최대 5개)다.
- 기능명세서 링크는 저장할 때 실제로 읽어 잘못된 링크와 권한 문제를 바로 알린다.
- 같은 원문 판별은 문서 내용이 아니라 문서 ID로 한다. 문서가 고쳐져도 같은 화면은 기존 해석을 열고, 변경은 알림으로만 표시한다. 내용이 빠진 판별값은 저장하지 않고 원문에서 다시 계산한다.
- 팀원 개인 Codex에는 기본 AI의 모델 ID를 넘기지 않는다. 다른 제공자의 ID면 실패하기 때문이다.
- 팀원 화면에서 동기화 버튼, 모델 선택, 화면 삭제와 부가 설명을 뺐다. 개인 코드는 자동 생성한다.

| 팀 서버 모드 브라우저 | 팀원에게 설정이 보이지 않음, 틀린 비밀번호 거부, 맞으면 네 구역 표시, 기능명세서 키 없음 오류와 API 명세서 저장 확인 |
| 로컬 모드 브라우저 | 비밀번호 없이 프로젝트 설정 표시, 콘솔 오류 없음 |

`npm run prove`는 테스트 실행 경로를 바꾸지 않아 돌리지 않았다. 팀 서버 모드는 HTTPS 대신 로컬 프록시로 확인했다.

## 미확인

- 실제 Notion 키로 기능명세서를 저장하고 읽는 경로. 응답을 흉내 낸 테스트만 통과했다.
- 팀원의 실제 ChatGPT 로그인 완료와 그 계정으로의 분석.
- 실제 HTTPS 서버 배포.
- 백엔드 연결, 프로젝트 추가, 화면 삭제는 팀 서버에서 화면만 숨겼고 서버 권한 검사는 없다. 접속 링크를 비공개로 유지한다는 전제다.
