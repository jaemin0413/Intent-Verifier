# 2026-11-09 작은 서버에 맞춘 메모리 최적화

대상 서버의 앱 VM은 RAM 2.5GiB, 가용 약 1.1GiB이고 같은 VM에서 다른 서비스가 계속 돈다. VM 구성은 바꾸지 않고 앱만 줄였다.

## 측정

| 항목 | 이전 | 이후 | 조건 |
| --- | ---: | ---: | --- |
| `state.json` | 87.5MB | 3.8MB | 실제 데이터(기능 65개) |
| 앱 서버 최고 메모리 | 2.2GB | 159MB | 목록 40회, 전체 화면 열기, 상태 변경 200회. 힙 128MB |
| 검사 빌드 (5개 시나리오) | 922MB | 740MB | Windows, 프로세스 합계 |
| 검사 빌드 (21개 시나리오) | | 692MB, 첫 실행 822MB | Linux 컨테이너 전체, 1.1GB 제한, 깨끗한 clone, 21/21 통과 |
| AI 호출 1회 | Claude 211MB, Codex 94MB | 같음 | 작은 입력 |

힙 96MB, 72MB도 부하 시험을 통과했지만 Java 소스를 읽는 실제 작업의 여유를 위해 128MB로 정했다. 테스트 힙은 128MB에서 실패했고 192MB부터 통과했다. 큰 화면을 고려해 256MB를 기본값으로 둔다.

## 변경

- 화면 노드·이미지, API 후보, 이력, Notion 진행 정보를 `feature-details/<기능>.json`으로 분리했다. 필드에 접근할 때만 읽으며 호출 코드는 그대로다. 기존 상태는 시작할 때 자동으로 옮기고, 기능 65개의 승인 digest와 목록 값이 전후로 같음을 확인했다.
- Gradle과 테스트 JVM 상한은 도구의 실행 옵션과 init 스크립트로만 적용한다. 대상 빌드 파일은 건드리지 않는다. 이전 검사가 남긴 생성 테스트는 컴파일에서 뺀다.
- 메모리 부족으로 끝난 실행은 FAIL을 포함해 BLOCKED로 남긴다.
- AI 호출과 빌드는 작업 게이트를 거친다. 빌드는 AI와 겹치지 않고, VM의 여유 메모리가 AI 350MB, 빌드 900MB 미만이면 기다린다.
- 대상 빌드 프로세스에는 도구의 비밀값 환경 변수를 넘기지 않는다.

## GitHub 코드 연결

서버에서는 개발자 PC의 폴더를 볼 수 없다. API로 파일만 읽어서는 Gradle 빌드를 돌릴 수 없어서, 서버가 저장소의 전용 사본을 받는 구조로 했다.

- 새 `BackendCheckouts`로 커밋을 받아 실제 Claude로 생성·실행까지 돌렸다: PASS 5, 원본 변경 없음, 결과에 브랜치와 커밋 기록(로컬 저장소를 원격 대신 사용).
- 컨테이너에서 실제 `github.com`에 등록되지 않은 키로 접속해 `Permission denied (publickey)`를 받았다. 호스트 키 고정과 안내 문구가 동작한다.
- 저장소에 파일이 없어 깨끗한 사본에서 실패할 가능성은 위 21/21 실험으로 확인했다. 이 대상 프로젝트는 설정 파일이 저장소에 있다.
- 실행 중 AI가 268자로 잘린 코드를 돌려줘 전체가 BLOCKED로 끝나는 경우를 봤다. 이제 수정 시도로 처리한다.

## 실제 서버에서 확인한 것

같은 VM에서 운영 서비스가 도는 상태로 Compose 배포까지 돌렸다.

- 이미지 빌드(2.78GB) 중 최저 여유 메모리 1297MB, 운영 서비스 정상.
- 범용 샘플을 앱 컨테이너에서 빌드 컨테이너로 실행: PASS 1, FAIL 1, 62초. 빌드 컨테이너 최고 621MiB, 최저 여유 메모리 882MB, 운영 서비스 재시작 없음. AI 응답은 고정값이다.
- 실제 GitHub 저장소에 읽기 전용 배포 키를 등록해 브랜치 목록과 커밋을 받았다.
- GitHub 조직이 배포 키를 막아 둔 저장소는 등록이 거절된다(`Deploy keys are disabled for this repository`).
- Gradle 배포판을 GitHub가 504로 거절해 wrapper가 시작 전에 실패한 경우가 있었다. 생성 코드와 무관하므로 AI 수정 없이 BLOCKED로 끝낸다.

## 확인하지 못한 것

- 컨테이너 안에서 실제 AI 호출까지 이어진 전체 검사.
- 공개 주소를 거치는 HTTPS 접속, 긴 요청, 실제 서버 기준 Figma 호출.

빌드는 별도 컨테이너에서 돌아 앱의 비밀값을 읽지 못하지만 외부 네트워크는 쓴다. 신뢰하는 팀 저장소만 연결한다.
